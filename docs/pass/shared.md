# proton pass shared

Items other people have shared with you.

Every command under `proton pass shared`, with the arguments and flags it takes. For these commands in use, see [the pass guide](README.md).

Holds `list`.

## `list`

List the items other people have shared with you.

These are in no vault of yours, so `items list` does not show them. Address them by the ID shown here, or by name.

An item whose content cannot be decrypted is still listed, so you can still act on it.

```
proton pass shared list
```

```bash
proton pass shared list
```

---

Every command also takes the [flags that work everywhere](../about/commands.md#flags-that-work-on-every-command).
