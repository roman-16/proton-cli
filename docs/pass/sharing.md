# proton pass sharing

Items you have shared with other people.

Every command under `proton pass sharing`, with the arguments and flags it takes. For these commands in use, see [the pass guide](README.md).

Holds `list`.

## `list`

List the items you have shared with somebody on their own.

To check a single item instead, run `items share get REF`. Shared vaults are in `vaults list` with the number of people in each, and secure links are in `links list`.

```
proton pass sharing list
```

```bash
proton pass sharing list
```

---

Every command also takes the [flags that work everywhere](../about/commands.md#flags-that-work-on-every-command).
